# WBACC Studio на Excalidraw — план

Одлуки на сопственикот, 27 септември 2026:

- **Excalidraw (MIT)**, не tldraw: од SDK 4.0 (септември 2025) tldraw бара клуч
  за лиценца на секоја објавена адреса и без него престанува да црта по 5
  секунди; бесплатната „hobby“ лиценца бара и знак „made with tldraw“. Тоа е
  токму надворешната зависност од која апликациите треба да се чуваат.
- **Една самостојна датотека**, `WBACC.html`, изградена од `wbacc/`. Работи
  без интернет: на GitHub Pages, на локалниот сервер, во облакот и отворена од
  дискот. Изворот (`wbacc/`) серверот не го објавува; објавена е само готовата
  датотека (`lib/public-static.ts`).
- **ComuniBoard останува** каков што е, додека новото не се докаже. Зачуваните
  табли во него не се допираат.
- **Обележувачите (Bookmarks+) во базата на MTB, само за сопственикот**, со
  копија во прелистувачот за да работи и без сервер.
- Цртежот останува во прелистувачот (IndexedDB), не во базата — независно од
  MTB, како што бараше сопственикот.

## Фонтовите — зошто работи без интернет

Excalidraw ги вчитува фонтовите од адреса (`EXCALIDRAW_ASSET_PATH`, па CDN), а
една датотека нема адреса. Неговиот вчитувач прифаќа и `data:` URL, па
`wbacc/vite.config.js` при градење ја заменува адресата на секој латиничен и
кириличен фонт со самиот фонт (~0,5 MB). Кинескиот Xiaolai (13 MB) останува на
CDN: без интернет неговите знаци се заменуваат. Проверено: македонски текст
(ѓ ќ ѕ џ љ њ) со Excalifont, 0 барања кон интернет.

## Фази

1. ✅ **Excalidraw офлајн** — една датотека (8,2 MB; 2,9 MB компресирано),
   автоматско зачувување во IndexedDB, избор на јазик (нема македонски
   интерфејс; бугарски/руски/украински се најблиску), воден жиг „изработил …“.
2. ✅ **Пиктограми** — „🖼 Пиктограми“: пребарување во ARASAAC (македонски, па
   англиски; бара интернет по природа); картичка = слика + збор под или над
   неа, една група; сликата се чува ВО цртежот, па картичката се гледа и без
   интернет. „🔊“ ги чита означените зборови (македонски глас ако системот
   има, инаку најблискиот словенски). Заслугата за ARASAAC видлива.
3. ✅ **Обележувачи** — „🔖 Обележувачи“: табли → колони → картички (линк,
   наслов, ознаки, белешка, 📌), пребарување, ↘ во цртежот (YouTube како видео
   што се пушта, друг линк како текст со линк), увоз од BookmarksPlus и извоз.
   На серверот (047, `bookmark_state`), само за администраторот, еден документ
   со верзија: зачувувањето ја наведува верзијата од која тргнало; ако друг
   компјутер зачувал во меѓувреме — одбиено, а човекот избира „⬇ Земи ги од
   серверот“ или „⬆ Препиши го серверот“. Празно не брише полно. Копија во
   прелистувачот: работи и без сервер, се праќа кога серверот ќе се врати.
   Датотеките закачени во BookmarksPlus живеат само во тој прелистувач — при
   увоз патува нивното име (📎 во белешката), не датотеката.
4. ✅ **Објавување** — „Сите“ → алатки: WBACC Studio покрај ComuniBoard;
   `test:wbacc` (18 проверки, сè измислено, ниту едно барање надвор).

## Градење

```
cd wbacc
npm install
npm run build        # → ../WBACC.html
```

Потребно само кога се менува WBACC; самата датотека е во репото.
