- CLI чита во една repeatable-read/read-only трансакција; нема apply пат.
- Сите години се вклучени. Повторена професија е информација, не грешка.
- На 032 недостапниот employee_id останува недостапен, не измислен идентитет.
- Поправено: сурови driver грешки можеа да носат приватни детали. Сега се
  печати само безбедна оперативна порака и дозволен технички код.
- Поправено: недостапни категории/миграциски ledger не смеат да изгледаат како
  нула. Проверката сега одбива нецелосно читање со оперативна грешка.
- Migration тестот брои со истиот filename filter како runner-от. Старото
  очекување 33 било застарена асерција, не механизам за прескокнување миграции.
