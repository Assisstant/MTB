Фонтови

Избери од листата, впиши точно име од fonts.google.com, или ⤒ прикачи .woff2 / .ttf — прикачениот фонт се вградува во датотеката и во „Објави HTML". Празно = стандарден фонт.

GitHub

Скенот (десен клик → Скенирај слики) прави категории од имињата на папките; делата паметат релативни патеки — објавениот HTML мора да стои во истата папка / repo како сликите.

Токенот се чува само локално (IndexedDB) — не влегува во објавената верзија ниту во JSON експортот. Направи fine-grained token: github.com → Settings → Developer settings → Tokens, само за овој repo, Contents: Read and write.

Податоци

„Објави HTML" симнува копија од оваа страница со вградени дела — readonly верзија спремна за GitHub Pages / хостинг. Твојата работна верзија останува овде.
